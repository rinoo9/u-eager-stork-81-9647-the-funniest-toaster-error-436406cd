# The Funniest Toaster Error Message

An entry for the [make.fun bounty](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd): one line, at most 120 characters — the funniest error message a kitchen toaster would show its owner when something goes wrong.

## The entry

> Your bread has been upgraded to charcoal. No refunds.

The toaster reports a burnt slice in the deadpan voice of a software update notice: the bread was not ruined, it was *upgraded* — and the company policy that follows makes it clear nobody is getting their breakfast back.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is deterministic: it writes the single line above to `/output/entry.txt`.
